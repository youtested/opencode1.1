# OpenCode IDE for Acode

Connects the file you have open in Acode to the local OpenCode server.

- Pushes the active file (path, language, cursor line, content) to the server.
- Lets the agent read the active file, open a file, or stage an edit for review.
- Shows a confirmation before writing a staged change.

Start the server first from the main TUI, then install this plugin.
